# 🚀 안녕하세요, AI 기반 백엔드 엔지니어 차백호입니다.

> **"현실의 도메인 문제를 데이터와 AI 아키텍처로 해결하고, 웹 서비스의 안정성과 실무 자동화를 동시에 달성하는 개발자입니다."**

저는 사이트 사용자의 불편함과 운영자의 니즈를 분석하여 **업무 자동화 및 시스템 최적화**를 이뤄낸 탄탄한 백엔드 경험을 가지고 있습니다. 특히 **K-water에서 드론 영상 기반 지형지도 실사 이미지를 활용하여 시계열 시설물 관리 서비스**를 성공적으로 구현하며, 대용량 멀티모달 데이터 처리와 가시화 역량을 증명했습니다.

ASP.NET Core 기반 웹 서비스 개발 경험과
LLM, RAG, AI Agent 기술을 학습하며
AI Application 개발 역량을 키우고 있습니다

## 🌟 Core Projects & Experiences

### 🌊 K-water | 드론 영상 기반 시계열 시설물 관리 서비스 구축
- **Description:** 드론으로 촬영한 고해상도 지형지도 실사 이미지를 정밀 매핑하고, 시간의 흐름에 따른 시설물의 변형 및 위험 요소를 추적·관리하는 시계열 서비스 구현.
- **Key Deliverables:** 
  - 대용량 이미지/공간 데이터(GIS) 백엔드 파이프라인 최적화 및 시계열 인덱싱 설계.
  - 실무 운영자가 수작업으로 검포하던 시설물 모니터링 공정을 디지털화하여 관리 효율성 극대화.
- **AI Expansion:** 해당 경험을 바탕으로, 실사 이미지에서 이상 징후를 탐지하는 **Computer Vision 모델** 및 "특정 구역의 3개월간 변화를 요약해줘"와 같은 요구를 수행하는 **Multimodal RAG 에이전트** 설계 역량 확보.

### ⚙️ 사용자·운영자 중심의 비즈니스 로직 개선 및 업무 자동화 (RPA)
- **Description:** 실제 서비스 유저와 어드민 운영자들의 페인 포인트(Pain Point)를 직접 수렴하여, 반복적이고 비효율적인 업무 프로세스를 자동화하는 백엔드 시스템 구축.
- **Key Deliverables:** 
  - 레거시 데이터 분석을 통한 워크플로우 최적화 및 자동화 배치(Batch) 프로세스 안정화.
  - **LLM Function Calling(Tool Calling)** 인프라와 결합하여, 인간의 개입 없이 자연어로 시스템 명령을 내려 업무를 처리하는 **AI Agent 자동화 인프라**의 발판 마련.
